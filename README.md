## 📖 Overview

**UniMate** is an all-inclusive student productivity platform engineered with Flutter, tailored for university students who require a streamlined, digital academic command center.

From routine management and attendance telemetry to automated CGPA forecasting, document OCR scanning, mess expense auditing, and conversational AI assistance powered by **Google Gemini**, UniMate consolidates scattered campus tasks into an effortless, unified workflow.

## 🌟 Core Experience

### 🎯 Academic Essentials
*Predictable, automated academic progress tracking.*

- 📅 **Smart Routine Manager:** Visual class schedules with smart conflict detection.
- 📈 **Attendance Telemetry:** Real-time attendance percentage with minimum percentage shortage warnings.
- 📝 **Deadlines & Exam Countdown:** Visual calendar of upcoming quizzes, midterms, and finals.
- 🎓 **CGPA Forecasting Engine:** Dynamic GPA calculator with what-if scenario simulations.
- 🚌 **Campus Transport Schedules:** Instant bus route lookups and timing notifications.
- 👨‍🏫 **Faculty Directory:** Fast access to advisor emails, consultation hours, and department desks.
- 📚 **Library & Borrowing Vault:** Track borrowed literature and return due dates.

## 🛠️ Tech Stack

| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | Flutter (SDK 3.x) | Modern Cross-Platform Client |
| **Language** | Dart | Strong-typed application logic |
| **State Management** | Riverpod | Reactive, compile-safe dependency tree |
| **Backend** | Node.js + Express.js | Scalable REST API endpoints |
| **Database** | MySQL & Drift (SQLite) | Persistent Cloud & Local Storage |
| **AI Engine** | Google Gemini Generative AI | Conversational Academic Tutor |
| **Vision & OCR** | Google ML Kit Text Recognition | Edge Document Scanning |
| **Visuals** | `fl_chart`, `lottie`, `flutter_animate` | High-fidelity interactive graphics |
